# pichouse 0.3.0

Linux amd64 build. This release adds tagging with the Hydrus PTR, a new grid, and many face and character tools.

## Downloads

- `pichouse-linux-amd64` — the application.
- `ptr-sync-linux-amd64` — a CLI tool for the first sync of the Hydrus PTR tag database.

## New features

### Tagging and the Hydrus PTR

- Each grid cell has a tag icon. Click the icon to open a tag popover with autocomplete.
- Search with `tag:<name>` to find photos with an exact tag.
- The "Tagging" settings pane has a "General" tab. Select the tag icon mode (auto, hover, always, off) and shape (tag, dot, hash).
- Optional local copy of the Hydrus Public Tag Repository (PTR). Do the first sync with `ptr-sync`. The application refreshes the copy.
- The PTR settings tab can move the PTR database to a different location.
- The tag popover shows PTR tags for a photo. You can add them as your own tags. The grid menu has "Add PTR tags".
- The grid tag icon shows in the PTR color for photos that have PTR tags only.

### Photo grid

- Thumbnails crop to a square. Mouseover shows the full photo, with an optional fade.
- The crop moves to keep the largest face visible.
- New settings: thumbnail crop on or off, mouseover fade, and cell margin.
- Sort by folder. Sort photos with unassigned faces first or last.
- Hold Shift to see the file path in a tooltip.
- The grid keeps its scroll position when photos move out of the view.
- Large views load much faster.

### Viewer

- The viewer keeps the old image until the new image is ready.
- The viewer reads the next and previous images in advance.

### Faces and characters

- A green badge marks face-scanned photos, folders, and albums.
- A light-blue badge marks folders with unassigned faces.
- "Ignore faces" replaces "Do not scan". Ignored faces show with a grey frame.
- Quick face assignment in normal albums. Assign all one-face photos in a view or album to a person or character.
- Face boxes show person and character names in album views.
- A "Recent" quick-select for the last three persons and characters.
- "Assign faces one by one…" for character groups, with an Ignore button.
- The Faces and Characters views have collapsible "Identified" and "Unidentified" sections. The unidentified groups have a sort menu, including sort by similarity.
- Folder tiles show a 3x3 face mosaic.
- Alt+hover on a face or character tile shows a random photo preview.
- Stricter face and character grouping, with new grouping settings and a minimum group size.
- Faces removed from a group move into a new group.

### Albums and library

- Squash an album to show all photos of its sub-albums in one view.
- "Remove Empty Albums…" removes empty albums and folder rows that are gone from disk.
- New folders after the first scan stay unassigned. The sidebar shows them in a tree. Drag a node onto an album to file the full subtree.
- Tools menu: "Scan for New Folders".
- Virtual albums: "Path contains" rule, rule groups, and person and character pickers.
- A status bar indicator shows background jobs.
- A manual scan can stop a running reconcile.
- The library scan shows phase progress.

## Performance and fixes

- Many database queries are faster. New indexes, set-based statements, and fewer UI-thread queries.
- The person and character lists load faster.
- The New Files view is responsive with many files.
- Folder switch is instant. Thumbnails do not drop on fast scroll.
- Fix: a crop clamp panic from float rounding.
- Fix: the "scan already running" state could stay on.
- Fix: a new virtual album did not show until restart.
